# MOP Simulator V3.5.0 - Autonomous AI Penetration Research Platform (Frontend)

This is the Next.js frontend for the **MOP Simulator V3.5.0**, a high-fidelity advanced physics and penetration simulation platform.

## Getting Started

First, ensure the backend is running. Then, install dependencies and run the development server for the frontend:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the simulator UI.

## Technologies

- [Next.js](https://nextjs.org/)
- React
- Tailwind CSS
